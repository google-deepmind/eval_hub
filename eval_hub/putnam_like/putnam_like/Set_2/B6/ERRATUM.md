# Erratum

The original public release of Set_2/B6 stated the right-hand integral with
`\cos x`. That identity is false. The corrected integrand is `\sin x`.

The question and grading scheme in this directory have been corrected. Existing
files under `samples/` are intentionally left unchanged because they are
historical outputs and grades produced against the original released question.
They should therefore be interpreted as records of the pre-correction version,
not as responses to the corrected question.

See issue #7 for the derivation and numerical checks motivating this correction.
